# The Hollenbeck–Verbitsky (2010) conjecture is false

The paper: https://doi.org/10.5281/zenodo.23728903

What is in this repository:

- [lean/](lean/) - the Lean 4 proof of the paper's results. Click it to see the proof, what it takes as given, and how to check it.
- [programs/](programs/) - the paper's programs and their logs. Click it to see which statement each one checks and how to run it.
